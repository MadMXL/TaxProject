# Bills & Tax Manager

A simple billing and tax invoice management system for SMEs.

## How to Use

1. Open `index.html` in your web browser
2. Start managing your quotations!

## Features

- Dashboard with revenue overview
- Group bills by date or customer
- Create new quotations
- Generate PDF invoices
- Export data to CSV
- Mobile responsive

## Project Structure

```
bills-tax-clean/
├── index.html
├── css/
│   └── styles.css
└── js/
    ├── data.js
    ├── ui.js
    ├── functions.js
    └── app.js
```

## Customization

- **Change tax rate:** Edit `0.07` in `js/functions.js` (line 15 and 37)
- **Change colors:** Modify Tailwind classes in `js/ui.js`
- **Add company name:** Edit text in `js/ui.js` (line 8)

## Technologies

- HTML5
- CSS (Tailwind)
- JavaScript (Vanilla)
- jsPDF (PDF generation)
